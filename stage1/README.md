This directory gathers the repository's Stage 1 report snapshots, drafts and
presentation materials. The user has confirmed Stage 1 submission and that the
Drive PPT linked below is the actual final PPT. No independent Canvas receipt or
comparison against uploaded bytes is recorded here. The latest report snapshot
is not automatically identified as the report that was submitted.

The [native shared Google Doc](https://docs.google.com/document/d/1xvGO8EA_yZwWj1It3UM7AKDFEoQjsj5eJJXbCz4bcnc/edit)
remains the report revision entry point. The snapshots retain their original
bytes, metadata, dates and stated verification limits; those historical metadata
paths identify the source layout and are mapped to current paths above. This is
an archive with no automatic or bidirectional Drive sync.

The drafts retain their authorship, evidence and pending personal-review fields.
Publishing or relocating material does not supply a personal contribution,
review signature, R.04 acceptance or completion of B-owned M-S.03. Shared models,
requirements and frozen allocation stay in their existing canonical locations.
The user manages the actual recorded video; this directory does not schedule or
manage recording or delivery.
